# Moderator-Bot
Le bot de modération de l'Ordre des Devs

# Getting started
1. Créer un fichier `.env` dans la racine en suivant le fichier d'exemple `.env.example`
2. Configurer le post manager et le système de tickets dans `configuration/`
3. Installer les dependencies: `npm install`
4. Lancer le bot: `npm start`
